# 食料品店まで500m以上の人口（125mメッシュ）

国勢調査 125mメッシュ人口と食料品店 POI から、**食料品店まで道路距離が500m以上のところに住む人口**を
市区町村別に推計する。農水省「[食料品アクセス](https://www.maff.go.jp/j/shokusan/eat/access_genjo.html)」の
公表値は**突合の相手**として使う。

## ★ 推計するのは距離条件だけ

農水省の食料品アクセス困難人口の定義は3条件である。

> **店舗まで500m以上かつ自動車の利用が困難な65歳以上の高齢者**
> 対象店舗＝食肉、鮮魚、野菜・果実小売業、百貨店、総合スーパー、食料品スーパー、
> コンビニエンスストア、ドラッグストア
> — 農水省 [食品アクセス（買物困難者等）問題の現状について](https://www.maff.go.jp/j/shokusan/eat/access_genjo.html)

**本リポジトリが推計するのは第1条件（距離）だけ**で、自動車利用は掛けない。
自動車利用困難率を外部データで固定できておらず、公表値との比（0.42〜0.66）が
**自動車要因と店舗レイヤの穴のどちらに由来するか分離できない**ため、掛けると推計値の意味が
決まらなくなる。年齢条件も外せるように **65歳以上と総人口の両方**を出す。

したがって「◯◯市のアクセス困難人口は△△人」とは言わない。言えるのは
**「◯◯市で食料品店まで道路距離500m以上に住む65歳以上は△△人」**である。

## 推計結果（47都道府県・1,740市区町村）

店舗レイヤは ATP基準＋許可⑪（122,249店）。人口は令和2年国勢調査125mメッシュ。

| 判定 | 総人口 | 割合 | 65歳以上 | 割合 |
|---|---:|---:|---:|---:|
| **★D 道路距離500m以上**（主） | **41,333,085** | **32.8%** | **13,668,822** | **38.7%** |
| A 同一500mメッシュに店舗なし | 52,368,599 | 41.5% | 16,767,203 | 47.5% |
| C125 直線500m以上 | — | — | 9,070,750 | 25.7% |

> 母数は総人口 126,088,473 / 65歳以上 35,314,481人。
> 変種Dの分母は道路距離が定義できるメッシュに限る（アクセスリンク欠落 1,853メッシュ・
> 65歳以上 8,450人＝0.02% を除外）。

**主指標は変種D（道路距離）**。実際に歩く距離であり、地域間の順位づけが最良だから
（地方部の相関 rA 0.199 → **rD 0.258**）。変種Aは「同一500mメッシュ内の存否」なので
隣メッシュ10m先の店に救われず実効半径250m程度になる二値近似で、距離そのものを測っていない。

### 領域別（高齢者密度 1,500人/km² で分ける・店舗レイヤに依存しない区分）

| 領域 | 市区町村 | 65歳以上 | D 圏外率 | A 圏外率 | rD | rA | 比D>1 | 比A>1 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 全国 | 1,740 | 3,531万 | 38.7% | 47.5% | 0.337 | 0.304 | 173 | 78 |
| 都市部（≥1,500） | 154 | 1,280万 | 15.3% | 23.4% | 0.707 | 0.723 | **123 (80%)** | 72 (47%) |
| **地方部（<1,500）** | 1,586 | 2,251万 | **52.0%** | 61.2% | **0.258** | 0.199 | **50 (3.2%)** | 6 (0.4%) |

「比」は農水省公表値÷本推計で、**1を超えたら論理矛盾**（公表値は本推計の部分集合のはず）。
都市部で大量に破れるのは農水省の推計方法が確率版であるため（後述・issue #4）。
**地方部では道路距離でも 3.2% に収まる**が、破れは密度1,000〜1,500の郊外自治体
（愛知県の町部・八潮市・瑞穂町など）＝都市部との境界に寄っている。

姉妹プロジェクト [japan-transit-desert-analysis-125](https://github.com/shiwaku/japan-transit-desert-analysis-125)
（公共交通空白地域・国交省定義・**125mメッシュ版**）の**農水省版**にあたる。施設レイヤを外から受け取り、
メッシュ人口 × 距離判定で圏外人口を出し、省庁の公表値と突合する構造は同じ。
**参照実装は125m版**（`-125` の付かない250m版ではない）。メッシュ人口 `2020_pop_census_mesh125.parquet`・
GeoJSON→tippecanoe→PMTiles の流れ・ビューワの作りはあちらに合わせている。

- **人口**: 国勢調査2020 125mメッシュ（e-Stat 統計GIS `T001225`、**appId 不要**）
- **店舗**: [shiwaku/japan-food-store-master](https://github.com/shiwaku/japan-food-store-master) が生成する食料品店 POI マスター
- **正解**: 農水省 [表5 市町村別（2020年）](https://www.maff.go.jp/primaff/seika/fsc/faccess/attach/excel/2020_table05.xlsx)

## 47県で分かったこと（2026-08-27・issue #2）：公表値との整合は地方部限定

3県88市区町村では比>1 が0件だったが、全国に広げると**都市部で大量に破れる**（上表）。
千代田区は変種A圏外率 **0.1%** に対し農水省 4.5%（比 37.6）。密な市街地では全500mメッシュに
店舗があるので圏外がほぼ消えるが、公表値は数%ある＝**「圏内なのに困難人口」という論理矛盾**。
直線500m（変種C125）は圏外がさらに減るので**もっと悪化**し（比>1 399件・max 696）、
道路距離500m（変種D）でも解消しない（比>1 173件）。**「もっと厳しい／緩い」の軸に答えは無い。**

→ **「全市区町村で比≤1」という主張は取り下げ、「地方部では」と限定する。**
原因は 2026-08-28 に判明した（農水省の推計は確率版・後述）。

### さらに：ATP基準＋許可データの投入は、全国で測ると悪化している

| 系統 | 圏外率A | 比 | 比>1 | r（全国） | r（地方部） |
|---|---:|---:|---:|---:|---:|
| Phase1（102,984店） | 51.7% | 0.496 | **44件** | **0.305** | 0.177 |
| ATP基準＋許可（139,492店） | 45.2% | 0.567 | **102件** | **0.271** | 0.158 |

3県では「比≤1 維持・r 0.448→0.462 改善」で投入が正当化されていたが、47県では
**比>1 が倍増し r は悪化**する。純増が都市部に偏っているため。
→ japan-food-store-master 側の投入判断を全国で測り直す必要がある。

### 相関 r を投入可否に使うのは弱い

全国 r=0.271 は「都市は圏外率が低く困難人口も少ない／地方は逆」という**都市-地方のコントラストで
稼いでいる**。**地方部内では r=0.158** しかなく、地方の市区町村を相互に並べ替える力はほとんど無い。
→ 純増が都市部に多いソースは、地方の穴を1つも埋めなくても r を動かせる。判定は**地方部限定の r** で見る。

## ★ 農水省の推計方法が判明した（2026-08-28・issue #4）

農林水産政策研究所の研究成果報告会資料
[240319_01.pdf](https://www.maff.go.jp/primaff/koho/seminar/2023/attach/pdf/240319_01.pdf)
スライド5に推計方法が明記されている。

> - 人口のある500mメッシュ単位に、当該及び周辺メッシュの店舗状況から、**最も近い店舗が
>   500m以上である確率**を算出。
> - **この確率に人口を乗じて**、メッシュごとに店舗まで500m以上の人口を推計。

添付図は「各メッシュにおける500m以上の確率 **× 半径500mの円**」、3×3メッシュに
確率 0.939 / 0.828 / 1.000 / 0.385 / **0.028** / 0.955 / 0.598 / 0.259 / 0.989 を振り、
「メッシュ22内の位置 k」と注記している。

**つまり農水省の判定は二値ではなく確率（メッシュ内位置についての面積比）である。**
ここで比べてきた変種A/C/D は全部二値なので、構造が違う。
これが都市部で比>1 が出る理由を説明する — **店舗のあるメッシュでも確率は0にならない**
（図の中心メッシュが 0.028）ので、千代田区のように「全メッシュに店舗があるのに公表値が数%ある」
状態が自然に出る。従来推計の店舗データが**商業統計メッシュ統計＝メッシュ別件数（座標なし）**
なので、店舗位置もメッシュ内で不確実として扱う確率モデルになっている、という読み。

同資料から確定した他の事実:

| 項目 | 内容 |
|---|---|
| 距離 | **直線500m**（道路距離ではない） |
| 店舗データ | 2020年推計は**2021年スーパー名鑑等**（〜2015年推計は商業統計メッシュ統計） |
| 業種 | 2020年推計で酒・菓子パン小売業を**除き**ドラッグストアを**追加** |
| 自動車利用率 | **家計調査個票**（〜2015年推計は全国消費実態調査） |

→ 残る宿題は「確率版を実装して都市部の公表値が再現できるか」。issue #4 で追う。

## 二値近似の中では変種Aが最も整合する

「500m以上」を二値で実装する候補を比べると、**同一500mメッシュ内の店舗存否（変種A）だけが
公表値と論理的に整合する**。農水省の困難人口は「圏外 **かつ** 自動車利用困難」なので、
比（農水省÷圏外人口）は必ず1以下でなければならない。

| 変種 | 操作化 | 圏外率 | 比 中央値 | 比>1 の市区町村 |
|---|---|---|---:|---:|
| **A** | **同一500mメッシュ内に店舗があるか** | 62.4% | 0.365 | **0件** ✅ |
| B | 自メッシュ+8近傍メッシュ | 26.6% | 0.592 | 多数 ❌ |
| C125 | **125m**メッシュ重心から実距離500m以内 | 40.5% | 0.501 | 5件 ❌ |

> 3県88市区町村・65歳以上 1,107,739人。B は500mメッシュ人口での実測値（`docs/` 参照）。

**125mメッシュにしても変種Cの不整合は消えない。** 当初は「500mメッシュ重心が実際の居住位置から
最大 ~350m ずれるせい」を疑ったが、重心誤差を ~88m まで落としても比>1 が残った
（Phase1マスターで5件、ATP基準＋許可データで10件・max 4.237）。
→ **農水省の指標は直線500m円ではなくメッシュ存否である**という結論は、重心の粗さに由来しない。

これは設計に直接効く。**隣メッシュの店舗には救われない**＝1店の欠落が1メッシュ全員を圏外に振り替えるため、
**店舗レイヤの網羅性が距離指標に直に効く**。

## 参考：3県での実測（88市区町村・65歳以上 1,107,739人）

**3県での判定は当てにならない**（47県で結論が逆転した実例が複数ある）。記録として残す。

### 変種A

| 人口レイヤ | 店舗レイヤ | 圏外率 | 比 農水省÷A | 相関 r | 比>1 |
|---|---|---:|---:|---:|---:|
| 500mメッシュ | Phase1（102,984店） | 62.2% | 0.420 | 0.448 | 0件 |
| 500mメッシュ | ATP基準＋許可（139,492店） | 57.3% | 0.456 | 0.462 | 0件 |
| **125mメッシュ** | Phase1 | **62.4%** | **0.416** | **0.451** | **0件** |
| **125mメッシュ** | ATP基準＋許可 | **57.4%** | **0.452** | **0.454** | **0件** |

**変種Aは人口を125mにしてもほぼ動かない**。500mメッシュ単位の判定は同じで、子16メッシュの和が
親メッシュに一致するため数学的にそうなる。変わるのは市区町村境での割当精度だけで、
実際 65歳以上人口が 1,101,938 → 1,107,739（+5,801人）と精緻化された。

### 変種C125（対照・実距離500m）

| 店舗レイヤ | 圏外率 | 比 農水省÷C125 | 相関 r | 比>1 |
|---|---:|---:|---:|---:|
| Phase1 | 40.5% | 0.642 | 0.499 | 5件 ❌ |
| ATP基準＋許可 | 36.6% | 0.711 | 0.480 | 10件 ❌ |

相関 r は変種Aより高い（0.499 / 0.480 vs 0.451 / 0.454）が、**論理整合（比≤1）を満たさない**。
公表値の再現には使えない。

## 判定：この推計は何に耐えるか

### ✅ 耐えている: 500m圏外人口そのもの（距離条件だけ）

推計しているのは店舗レイヤと道路ネットワークから直接計算できる量なので、**係数も外挿も無い**。
誤差は入力（店舗レイヤの網羅性・ネットワークの粒度）にのみ由来する。

### ✅ 耐えている: **地方部での**相対比較・スクリーニング

**地方部1,586市区町村（高齢者2,251万人）では公表値との比>1 が 3.2%（変種D）/ 0.4%（変種A）**
しか出ない。「どの市区町村・どの集落が相対的に厳しいか」の判定に使える。

### ❌ 耐えていない: 都市部で農水省の公表値を再現すること

都市部154市区町村では比>1 が 80%（変種D）/ 47%（変種A）出る。
農水省の推計が確率版だからで（上記）、二値判定である限り解消しない。**issue #4**。

### ⚠ 店舗レイヤ由来の誤差は残る

**隣メッシュの店舗には救われない**（変種A）／1店の欠落が周囲のメッシュを丸ごと圏外に振り替える。
市区町村単位の店舗レイヤ由来誤差は概ね **±20〜30%**。**絶対人数を1桁目まで信じないこと。**

### ❌ そもそもやっていない: アクセス困難人口の推計

自動車利用を掛けていないので**困難人口ではない**（冒頭参照）。

## 地図で見る

125mメッシュ 2,814,449件を PMTiles にして MapLibre で表示する。
作りは姉妹リポジトリ **japan-transit-desert-analysis-125** に合わせてある
（`docs/index.html` + `docs/pale.json` + `serve.py`、住所検索・2D/3D・ボトムシート）。

**既定は変種D（道路距離）**。右上の「道路距離／メッシュ」ボタンで判定方式を切り替えると、
色・凡例・集計・ポップアップ・住所検索の判定がまとめて追従する。

| 区分 | **D 道路距離**（既定） | | A メッシュ存否 | |
|---|---:|---:|---:|---:|
| | メッシュ | 65歳以上 | メッシュ | 65歳以上 |
| 🟢 スーパーあり | 294,958 | 894万人（25.3%） | 328,594 | 948万人（26.8%） |
| 🟠 コンビニ・ドラッグストア・生鮮のみ | 618,131 | 1,270万人（36.0%） | 421,730 | 907万人（25.7%） |
| 🔴 **500m圏外** | 1,901,360 | **1,368万人（38.7%）** | 2,064,125 | **1,677万人（47.5%）** |

> **これは「500m圏外」であって「アクセス困難」ではない。** 農水省の困難人口は
> 「500m以上 **かつ** 自動車の利用が困難」で公表値は全国904万人（25.6%）。
> このマップは**距離条件だけ**を表示している。

道路距離の算出方法は姉妹リポジトリ **japan-transit-desert-analysis-125** を踏襲している
（`scripts/04_road_distance.py`）。**区分はタイルに焼いていない**（`out_a` / `out_d` と `sm` から
MapLibre の式で導く）ので、判定の切り替えにタイルの作り直しは要らない。

```bash
python scripts/04_road_distance.py      # 道路距離（Multi-source Dijkstra・全国126秒）
python scripts/03_export_pmtiles.py     # GeoJSONL 生成（DuckDB）＋ tippecanoe があれば実行
bash output/make_pmtiles.sh             # tippecanoe を別途走らせる場合（WSL 等）
python serve.py 8080                    # http://localhost:8080/docs/ （Range 対応が必要）
```

PMTiles（約300MB）と GeoJSONL は `.gitignore`。公開時は外部ホスティングに置く（`docs/index.html`
の `PMTILES_URL` が localhost では `../output/` を、それ以外では外部URLを見る）。

## 使い方

```bash
pip install -r requirements.txt

# 1. 125mメッシュ人口を取得（e-Stat 統計GIS・appId不要・キャッシュあり）
python scripts/01_fetch_mesh_population.py 高知県 島根県 宮城県

# 2. 店舗レイヤを input/ に置く（japan-food-store-master の出力）
#    必要な列は lat / lng / cat の3つだけ
#    cat = supermarket / convenience / drugstore / fresh_food

# 3. 主指標（変種D）の道路距離を作る。**02 と同じ店舗レイヤで作ること**
#    道路ネットワークはリポジトリ外（NETWORK_DIR で指定・全国126秒）
FOOD_STORES=input/food_store_master_atp_super.parquet \
    python scripts/04_road_distance.py

# 4. 500m圏外人口を出して農水省公表値と突合
FOOD_STORES=input/food_store_master_atp_super.parquet \
    OUT_SUFFIX=_ATP⑪ \
    python scripts/02_validate_access_difficulty.py 高知県 島根県 宮城県
```

`04` を飛ばすと変種Dの列が落ち、変種A/C125 だけで走る（道路ネットワークが無い環境向け）。

`make all` でも同じ（`Makefile` 参照）。境界データ・農水省の表5 はスクリプトが自動取得してキャッシュする。

### 店舗レイヤの差し替え

`FOOD_STORES` と `OUT_SUFFIX` で入出力を差し替えられる。**既存の CSV を実験結果で上書きしないこと。**
「あるソースを投入したら圏外人口がどう動くか」を、店舗マスター本体を書き換えずに測るための入口。
変種Dを使うなら `04_road_distance.py` も**同じ店舗レイヤで**回し直す（`ROAD_DIST` で出力先を分ける）。

**投入の可否は圏外率が下がったことでは判定しない**（件数を足せば必ず下がる）。
**「比 農水省÷本推計 が1を超えないこと」**と**「相関 r が上がること」**を
**地方部（高齢者密度 < 1,500人/km²）に限定して**見る。両方スクリプトが出す。
**3県だけで判定してはいけない**（47県で結論が逆転した実例が複数ある）。

そのときの候補は全国家計構造調査の高齢者世帯 自動車保有率、および農水省が使っている
**家計調査個票**（2024-03-19 資料で判明）。
